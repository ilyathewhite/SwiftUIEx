# SwiftUIEx

General extensions that might be useful in any project

Requires Swift 6.0 or later and builds in Swift 6 language mode.

## Installation

```swift
.package(url: "https://github.com/ilyathewhite/SwiftUIEx.git", from: "1.1.0")
```

See the [changelog](CHANGELOG.md) for migration notes and release details.
